Документация СмИТ Биллинг 3.5

Добро пожаловать в документацию системы СмИТ Биллинг 3.5 — биллинговой платформы для операторов связи и сервис-провайдеров.

Веб-интерфейс биллинга: billing.smit34.ru
Технологический стек: Python 3.11, Django 4.2 LTS, PostgreSQL 16, Redis 7, Celery 5, FreeRADIUS 3.2.3, Docker Compose, Gunicorn, Nginx, AdminLTE 3 + Bootstrap 5.3.

Установка и интеграция

Docker Compose развёртывание, системные требования, миграция данных, видео-инструкции.

Основные настройки биллинга

Управление клиентами, тарификация, платёжные системы, отчёты, справочники.

ЛК и мобильные

Личный кабинет клиента (/lk/), мобильные приложения Android+iOS, брендинг, Public Mobile API, force-update.

Поддержка (HelpDesk)

Тикеты, каналы приёма (email/TG/VK/MAX/голос), AI-бот, база знаний, голосовая почта, аналитика и время ответа.

CRM — продажи

Воронки и конструктор, источники сделок, доп. поля, задачи, Salesbot, виджеты, дашборд с картой, UTM-кампании.

Лендинги

Конструктор сайтов: 23 блока, слайдер, видео-фон и эффекты, формы в CRM, публикация на поддомене, AI-генерация.

Управление сервером

Docker-контейнеры, PostgreSQL, Celery, обслуживание, удалённое управление.

Интеграция с оборудованием

NAS/BRAS, коммутаторы, VoIP-шлюзы, IPTV, абонентское оборудование.

Интеграция с СОРМ3

Передача данных по ФЗ, стандартные и пользовательские схемы СОРМ.

API

REST API v2, SOAP, Mobile API (JWT), обещанный платёж, управление клиентами. Примеры curl и JSON.

Решение проблем

FAQ, диагностика авторизации, сети, платежей, мониторинг сервера.

Лицензирование и оплата

Порядок поставки ПО, решение проблем с оплатой, акты сверки.

Контакты

Отдел продаж, техническая поддержка, партнёрство.
